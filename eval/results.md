## 评测 2.0:图表选型准确率 + 延迟 p50/p90(2026-11-01,4 配置 × 3 轮跑批)

指标脚本 `eval/metrics.py`(纯函数,可对任意跑批明细回放;`--markdown` 直接输出表行)。期望图型逐题标注在
`eval/questions.py` 的 `CHART_EXPECTATIONS`;`run_eval.py` 把 `chart_*` 与 `p50/p90_latency_ms` 写进跑批 summary。

口径:

- **期望图型**按题目意图标注(`line / bar / arc / point`,None = 按契约不出图),只看题目与标准答案形状,**不看某次跑批结果**;
- **选型准确率** = 应出图题(期望非 None)中,产出 mark 与期望一致的题数 / 应出图题数;
- **延迟** = 单题端到端 `latency_ms`(含 LLM 多轮 + SQL 执行),p50/p90 线性插值(与 numpy 默认同法);
- 单值/排序题被模型答成完整榜单后补出图表:表可画、契约允许,记"榜单扩展"(extra),**不计选型错误**;
- 一轮 = 4 个配置各跑 1 次(每次 50 题);"注入⚡"= 每题首条 `execute_sql` 的表名被强制改错,衡量恢复能力。
