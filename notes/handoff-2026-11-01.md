## 已确认的下一步：评测 2.0（用户 2026-11-01 选定）

原则：只改 `eval/` 与脚本，**不动 agent 主循环**；主链路回归 99 例必须仍绿。

1. **图表选型准确率**：从跑批记录（`records`/`chart_spec`）自动判 mark 类型
   （line / bar / arc / scatter）是否符合题型预期，产出"选型准确率"新指标。
2. **解读忠实性**：校验解读文本里的数字 ⊆ 最终结果表的数字，防模板漂移
   （模板生成，适合规则校验；不引入新 LLM 调用）。
3. **无法回答 / 歧义题 10 道**：例如"2013 年退货率"（库无退货字段）、
   "销售额最高的市场"（缺年份限定）；测是否优雅降级/澄清，而不是硬编 SQL。
4. **延迟分布**：p50 / p90（现有记录已有 `latency_ms`，直接汇总）。

验收：可复现脚本 + `eval/results.md` 新增一节 + README 更新；`pytest tests -q` 99 例仍绿。

建议顺序：1 → 4（都基于现有 records，最便宜）→ 2 → 3（要新题）。
