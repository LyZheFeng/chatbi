# chatbi 项目报告:数据库 + 每一轮优化的测评结果

> 由 `scripts/make_report.py` 从 `data/chatbi.db` 与 `eval/runs/*.json` 现算生成。
> 共 74 个跑批文件、3,164 题次;
> 下文按**优化轮次**组织:每轮先写改了什么,再贴该轮的测评结果,最后给说明。

## 一、数据库

- SQLite 单文件 `data/chatbi.db`(516 KB),只读连接 `file:...?mode=ro`
- Global Superstore 电商订单:5 张关联表;DDL 内嵌中文列注释,枚举取值由数据动态算入注释
- 确定性注入 5 类脏数据,可复现

| 表 | 行数 | 列 |
|---|---|---|
| `customers` | 800 | customer_id, customer_name, segment, city, state, country, region, postal_code |
| `geography` | 96 | country, region, market |
| `order_items` | 1000 | row_id, order_id, product_id, sales, quantity, discount, profit, shipping_cost |
| `orders` | 867 | order_id, order_date, ship_date, ship_mode, order_priority, customer_id |
| `products` | 529 | product_id, product_name, category, sub_category |

| 脏数据 | 数量 |
|---|---|
| customers.postal_code 为 NULL | 752 |
| customers.region 为 NULL | 2 |
| order_items.quantity ≤ 0 | 3 |
| order_items.sales 为 NULL | 2 |
| orders.ship_date < order_date | 2 |

| 低基数列 | 取值(DDL 注释来源) |
|---|---|
| `market` | Africa / Asia Pacific / Europe / LATAM / USCA |
| `segment` | Consumer / Corporate / Home Office |
| `category` | Furniture / Office Supplies / Technology |
| `sub_category` | Accessories / Appliances / Art / Binders / Bookcases / Chairs / Copiers / Envelopes / Fasteners / Furnishings / Labels / Machines / Paper / Phones / Storage / Supplies / Tables |
| `ship_mode` | First Class / Same Day / Second Class / Standard Class |
| `order_priority` | Critical / High / Low / Medium |

## 二、评测口径

- 题库 54 题(50 基础 + 4 图型补题),每题一句 gold SQL;两边各自执行成表再比值集合
- 严格口径:值集合一致、行序无关、列子集投影、单行 gold 答案点包含;
  严格失配再拆「内容缺失」(宽松也救不回)与「形状差异」(多返回行/百分比/标签)
- 宽松口径(并列报告):放宽多返回行、比率↔百分比、月份标签带不带年份
- 其他指标:图表选型(逐题标注期望 mark)、延迟 p50/p90、解读忠实性(数字必须可追溯)
- 专项:10 道歧义/无解题(判「澄清/降级/写明口径」);故障注入(改错首条 FROM/JOIN 后的业务表)

### 优化 #3:解读忠实性(19:27 → 19:42)

**问题**:模板解读可能写死/漂移数字,没人验证它是否来自结果表。

**改动**:`eval/fidelity.py` 抽解读数字,从结果表独立重算允许集合(单元格/列和/分组和/占比/
